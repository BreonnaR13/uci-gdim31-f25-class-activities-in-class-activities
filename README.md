### W2

1. Why are the r, g, and b variables floats instead of ints, bools, or strings?

These three variables are floats because they need to be values between 0 and 1 which are decimals. An int wouldn't work because ints are used for whole numbers and bools are for true and false values.

2. Why is the _bounce variable an int instead of a float, bool, or string?

The _bounce variable is an int instead of float, bool, or string because the bounce variable counts the amount of times the ball bounces. The amount of time it bounces can't be a float because floats are used for decimals. It can't be a bool because that would be true or false and would not be able to count the number of bounces. A string would also not work because integers are needed to count the bounces and strings are used for things like names and labels.
